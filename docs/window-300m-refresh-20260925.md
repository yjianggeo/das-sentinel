# 300 m 模型更新训练（2026-09-25）

使用现有数据完成一轮30秒、100 Hz、300 m以后通道的地震/噪声二分类训练。地震包含爆破，噪声包含车辆。沿用6137参数波形残差CNN、760×3000输入、Adam 0.001、10轮、seed 42，训练代码未改动。

本轮冻结3091窗：168地震、2923噪声。比2026-09-23更新训练增加331个逐窗人工确认的噪声窗口；旧标签修改0、排除0。标签来源分别为1108逐窗人工、36历史正标签导入、1947批量规则背景。三种距离网格已统一为834道原生网格，再按物理距离裁剪至760道。

train为117正/2046负，dev为25正/439负，test为26正/438负。按日期、目录事件、源指纹与读取区间联通分组。新分组改变了部分旧样本角色，因此重新初始化权重，不直接载入已见过本轮留出数据的旧权重。新增的5个独立日期全部是负例，且没有进入test；本轮仍是历史分组留出诊断。
