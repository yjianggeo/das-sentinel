# 井下广覆盖的传播测量与共模风险

用户已确认：保留地震／噪声二分类，在独立的井下广覆盖复核分中增加沿缆表观传播与保守的持续共模风险判断。该测量只调整复核排序，不改人工标签、CNN 输入、模型概率、原始数组或图件。

## 为什么使用长基线

100 Hz 缓存的采样间隔为 0.01 秒，数米道间距的真实传播时差常小于一个采样间隔。相邻道的零时差因此不能证明共模噪声。本次直接使用 500 m 以后有效道的滤波波形，固定选择空间分散的锚点，测量 500–1000 m 长基线相关时延，再检验多个基线的一致慢度。

显示的视速度是沿光缆坐标的表观速度，方向指距离坐标增大或减小，不代表真实岩层波速或物理上下方向。可信度描述此次传播测量的可靠程度，不是地震概率。

## 未确定的测量保留原分

窄带周期波的多个相关峰、低相关、不足的空间支持、有效道之间的明显空缺、边界截断、方向或时延不一致均不发布速度。相关时差未分辨也不显示无限速度，不作为噪声标签。

仅在多条长基线支持同步信号、窗内持续相干、前后背景均完整且充分、能量增益和相干突出程度较弱，同时未发现可靠传播或独立瞬态时，才标记“持续共模风险”。这些条件仍是保守的辅助证据，不能唯一确定噪声来源。

原覆盖分保存为 `coverage_score`，排序使用 `score`。有充分持续共模证据时初版扣除原分的 15%；未知、背景不足或存在真实瞬态证据时不扣分。此次不额外提高测得传播窗口的分数。

## 缓存与页面

新版缓存使用 `borehole-coverage-v2`。补算期间仍读取有效 v1 分数，保持队列可用；新写入只接受 v2，v1 缓存必须重新计算。缓存继续绑定分析 ID、输入哈希和当前处理配置，原覆盖计算保持一致。

复核摘要增加一个紧凑说明段，显示可测视速度或未确定状态、共模风险；实际扣分时显示原覆盖分到调整分。图件与模型得分继续保留。

## 验证边界

六个用户参考窗口与其余九个已有本地缓存对照只用于检查测量行为和原分一致性。它们不是独立测试集，也没有人工共模真值标签，不能据此宣称地震识别准确率提升或共模噪声已被彻底去除。

本次 15 个对照均未解析出可靠传播，共模状态均为未知、扣分均为零；六个用户参考窗口原分精确保留。合成测试覆盖非零传播、周期多峰、纯持续同步背景，以及背景上叠加的局部、反极性和边缘瞬态，后者必须保留原分。

最终纯测量聚焦测试 43 项通过，服务与图件 API 聚焦测试 59 项通过，前端全套 178 项通过并完成构建。后端全套在最后三项边界测试补充前为 1687 项通过、26 项跳过、1 项性能测试排除；最终三项边界已包含在 43 项聚焦结果中。
