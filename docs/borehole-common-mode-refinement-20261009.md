# 同相共模成分与残余覆盖复核

## 用户确认的行为

保持地震／噪声二分类与现有模型。独立测量 500 m 以后同相共模成分，并在私有内存副本上计算去共模后的残余覆盖。只有较强共模且残余覆盖弱时降低候选的井下广覆盖复核分，最多扣原覆盖分的 50%。原数组、图件、模型概率、人工标签和收藏均不修改。

有效人工确认地震的窗口使用原覆盖分排序和显示，仅提示共模风险。保护动态读取最新有效标签，不固化到测量缓存；改为待定或噪声后恢复候选分。

## 测量与边界

原生有效道时间去均值并按 RMS 归一化，保留正负极性；以空间中位数形成带符号模板。仅正投影计入共模解释比例及移除量，与模板反极性的通道不先翻转再归入共模。页面显示归一化正投影解释占比和残余覆盖分；它们不是地震概率。

可靠传播、较强残余广覆盖和独立道瞬态保护候选排序。证据不足、残余不可测或数值消去时保留原分。真实地震也可能同步到达，因此强共模不自动等同噪声，也不自动修改标签。

v3 缓存保留 v1/v2 的原覆盖和传播字段，新增 `common_mode_energy_fraction`、`common_mode_channel_fraction`、`residual_coverage_score`，支持 `component_supported` 状态。缓存继续绑定分析 ID、输入哈希和当前配置；补算只通过正常认证 API 写入。旧 v1/v2 在过渡期仍可读取，新写入仅接受 v3。
