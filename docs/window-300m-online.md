# JJK 300 m 整窗模型上线

2026-09-23，按用户要求发布上一轮距离对照的 300 m `residual_waveform` 残差 CNN。来源为 `window-distance-benchmark-20260923/ssd-comparison-v2/from-300m/residual_waveform`，选中第 7 轮，阈值 `0.03820184990763664`。权重 SHA-256 为 `eb488aa07a244bed1b72c7558e1af6f4eda165e7bb8863b25ad8d8bf9795f658`。本次不使用最新标签重训的第 9 轮模型。

## 输入与标签

输入为已生成的 30 秒、100 Hz 未滤波整窗数组。根据原 HDF5 的权威距离元数据，归一到固定的 834 道原生网格；保留有效道掩码，缺失道补零且不参与识别。再按实际距离裁剪到 ≥300 m，共 760 道 × 3000 点，实际首道约 302.658 m。裁剪先于稳健归一化；预处理与离线验证完全共用。

机器判断分为地震类（含爆破）与噪声类（含车辆）。得分 ≥ 阈值判为地震类。得分不是经过校准的置信概率。机器判断独立保存，不改变人工标签、推荐优先级、图件或传统规则疑似区域。

## 运行行为

- `/models` 显示本站点当前上线模型；已有训练任务继续保留为离线候选。
- 新成功完成的 30 秒扫描任务自动提交模型识别。传统规则跳过的空窗口仍按原流程跳过。
- 已有窗口在复核页打开时识别，期间显示“模型识别中”。没有批量重跑历史扫描。
- 预测按窗口、分析版本、输入摘要、模型版本缓存；输入或模型改变后重新识别。失败明确显示失败，可以重试，不会默认归为噪声。
- 推理队列在 API 进程内，单并发。API 重启会中断未完成预测；再次打开相应窗口会重新提交，不自动回补全部历史窗口。

API 服务使用原环境读取 HDF5/校验数据，Torch 子进程使用 `DAS_INFERENCE_PYTHON`（备用为 `DAS_TRAINING_PYTHON`）。本机均指向 `D:/das-sentinel-runtime/.venv-first-model/Scripts/python.exe`，不启动扫描 worker。单次子进程超时为 120 秒。

## 发布、验证和回退

发布命令为 `python -m das_sentinel.window_inference publish --source <模型目录> --manifest <冻结清单> --root <app-data/window-models> --site-id <站点ID> --name <显示名>`，需在 Torch 环境执行。发布检查站点、清单和权重哈希，复制不可变快照后原子更新站点 `active.json`。旧版本目录保留，`previous_id` 记录前版。

运行记录、独立前端产物和 API 专用启动脚本位于 `D:/das-sentinel-runtime/manual-work/window-300m-online-20260923`。旧前端产物保留，启动脚本复用现有登录密钥、数据库和 v2 检测配置。回退可将 `active.json` 原子改回已保留的前版；首次上线需要停用时，将该指针文件移至操作目录备份，模型快照和人工记录均保留。

验证覆盖模型发布完整性、推理输入契约、缓存/重试/过期状态、身份验证、扫描结果与推理失败隔离、页面切换及人工标签独立性。真实回放覆盖 3 种来源距离网格、5 个窗口（含阈值边界），与离线分数逐项一致。完整上线结果见操作目录的 `progress.md`。
