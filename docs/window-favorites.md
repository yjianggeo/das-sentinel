# 30 秒整窗事件收藏

## 使用

事件复核详情标题旁的“☆ 收藏”用于收藏已完成分析、已登记瀑布图的 30 秒窗口，再次点击“★ 已收藏”取消收藏。队列中的星标用于识别收藏窗口。

在“窗口范围”选择“只看收藏”即可浏览。进入该范围时，复核状态默认切换为“全部”，并清除模型扫描批次范围；也可使用 `/events?range=favorites`。站点、复核状态与分页筛选继续可用。

收藏与人工标签、推荐优先级、模型判断和训练数据相互独立。收藏操作不提交或清空正在编辑的复核内容。

## 保存与兼容

- `window_favorites` 使用 `(window_id, admin_id)` 主键，沿用现有单管理员登录机制。
- `PUT /api/v1/event-windows/{window_id}/favorite` 接收严格布尔值 `{"favorite": true|false}`，要求登录和 CSRF；响应包含窗口 ID、收藏状态及收藏时间。
- 重复收藏不会改写原收藏时间；取消收藏可重复调用。新增收藏要求当前分析成功且有瀑布图记录，已有收藏在重新分析期间仍可读取或取消。
- 列表和详情返回 `favorite` 字段；列表使用 `favorites_only=true` 在计算总数和分页之前筛选。
- 收藏关联稳定窗口 ID，重新分析不丢失收藏；自动跳过空窗口时保留已收藏窗口。显式删除窗口时外键级联删除对应收藏。
- 数据库迁移为 `0008_window_favorites`，仅新增收藏表及索引，保留既有窗口、分析、标签和模型。
