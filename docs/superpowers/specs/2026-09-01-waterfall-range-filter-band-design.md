# DAS Sentinel 瀑布图频段标注与人工 Distance 预览设计

日期：2026-09-01

## 1. 目标与范围

本次改动解决两个事件图件使用问题：

1. 明确显示滤波瀑布图实际使用的滤波频段及主检测器。
2. 允许复核人员按米输入 Distance 起止范围，临时重新生成原始与滤波瀑布图。

站点时区继续使用并显示有效 IANA 标识 `Asia/Shanghai`，不改为
`Beijing`，也不改变现有 UTC/站点本地时间计算。

人工预览不改变检测候选、融合事件、分类、特征、人工复核或现有审计图件；
不写数据库，不在 NAS 保存派生文件。波形、PSD 和 STFT 始终保持原事件结果。

## 2. 当前 Distance 与滤波频段语义

事件检测器分别产生 `channel_start` 和 `channel_stop`。融合阶段对同一事件
证据取通道范围并集，生成事件的自动通道范围。图件生成阶段将该范围裁剪到
读取数据的有效通道，排除坏通道，并使用 HDF5 中的通道物理位置映射生成
Distance 轴。因此，当前瀑布图 Distance 范围是检测和融合结果，不是固定范围，
也不是用户配置值。

滤波瀑布图使用事件主检测器对应的频率组。主检测器沿用现有确定性规则：按
得分降序，再按峰值位置和检测器名称稳定决胜。频段必须从该事件处理运行绑定的
配置快照解析，而不是从当前站点配置或硬编码默认值读取：

- STA/LTA：`stalta_freq_low_hz` 至 `stalta_freq_high_hz`；
- 能量检测：`energy_bands_hz` 的最低下限至最高上限；
- 相干检测：`coherence_freq_low_hz` 至 `coherence_freq_high_hz`；
- 轨迹检测：`trajectory_freq_low_hz` 至 `trajectory_freq_high_hz`。

## 3. 架构与接口

### 3.1 瀑布图选项接口

新增已认证只读接口：

`GET /api/v1/events/{event_id}/waterfall-options`

响应包含：

- 事件自动范围的最小、最大 Distance；
- 源文件全部通道的最小、最大可用 Distance；
- 主检测器规范名称与显示名称；
- 滤波下限和上限 Hz；
- Distance 单位 `m`。

该接口独立于事件详情接口。它可以读取源文件元数据，但不得读取完整信号块。
因此 NAS 离线或源文件不可用时，事件详情和既有审计图件仍能正常显示，只有人工
预览控制显示不可用提示。

### 3.2 临时预览接口

新增已认证、要求 CSRF 的接口：

`POST /api/v1/events/{event_id}/waterfall-preview`

请求体：

```json
{
  "distance_start_m": 100.0,
  "distance_stop_m": 500.0
}
```

响应包含：

- 实际选中的首末 Distance 和通道数量；
- 主检测器与实际滤波频段；
- 原始瀑布图 PNG 的 Base64 内容；
- 滤波瀑布图 PNG 的 Base64 内容。

选择采用单次 JSON 响应，是为了让后端只从 NAS 读取一次事件时间窗并只执行一次
滤波，同时向现有两个图件标签提供独立 PNG。两张 PNG 的体积受固定事件时间窗和
Matplotlib 输出尺寸限制；Base64 的传输开销可接受，且避免引入 ZIP 或 multipart
解析依赖。

后端处理流程：

1. 查询事件、源文件、原处理运行和处理配置快照。
2. 验证源路径仍位于配置的数据根目录下。
3. 使用源文件元数据验证请求范围。
4. 将闭区间 Distance 范围映射为源文件通道索引。
5. 读取现有事件时间窗；时间窗继续使用原事件起止时间和原配置
   `artifact_pad_seconds`，不接受用户修改。
6. 排除坏通道；范围内无可用通道时返回校验错误。
7. 使用原运行配置和主检测器频段执行与处理流水线相同的预处理。
8. 从同一次读取和预处理中生成原始、滤波两张临时 PNG。
9. 返回内存结果，不调用 ArtifactStore，不写文件或数据库。

计算前后都要检查源文件指纹，防止预览由读取过程中发生变化的文件生成。

## 4. 图件标注

页面获取瀑布图选项后，将滤波标签显示为：

`滤波瀑布图（2–40 Hz）`

标签附近同时显示：

`主检测器：STA/LTA`

新处理事件的永久滤波瀑布图，以及人工生成的临时滤波瀑布图，标题加入：

`Band-pass 2–40 Hz | primary detector=STA/LTA`

频率格式去除无意义的尾随零，但不降低非整数配置的精度。原始瀑布图不标为
“已滤波”，人工预览时可在标题中注明人工 Distance 范围。

既有永久审计 PNG 保持不可变。历史事件可在页面标签看到从原运行配置推导的频段；
按默认或人工范围生成临时预览后，临时 PNG 标题也会包含频段。

## 5. 页面交互

ArtifactViewer 上方增加 Distance 控制行：

```text
Distance 范围（可用 8–3404 m）  [起始 m] [结束 m]
                                  [生成预览] [恢复自动范围]
```

- 输入框初始值为事件自动 Distance 范围。
- 用户提交后，原始和滤波瀑布图同时切换到返回的人工范围临时图件。
- 波形、PSD、STFT 不变。
- “恢复自动范围”释放临时对象 URL，恢复永久原始图件，并恢复自动范围输入值。
- 切换事件时取消未完成请求、忽略迟到响应、释放临时对象 URL，并初始化新事件范围。
- 请求进行时禁用重复提交并显示“正在生成…”。
- 预览失败时保留当前图件和输入内容，显示可操作错误，不清空已成功预览。
- 全屏和下载操作针对当前显示图件；临时预览下载使用浏览器对象 URL，不访问
  ArtifactStore。

## 6. 输入校验与错误语义

前后端都执行相同的基础校验，后端为最终权威：

- 两个值必须是有限数字；
- `distance_start_m < distance_stop_m`；
- 请求范围必须完全位于源文件可用范围内，不进行静默截断；
- 使用包含边界的 Distance 选择；
- 排除坏通道后至少保留一个通道。

错误响应：

- 事件不存在：404；
- 数字、顺序、边界或无可用通道错误：422；
- 源文件缺失、指纹变化或与事件记录冲突：409；
- 无权限或 CSRF 无效：沿用现有 401/403 行为；
- 其他受控读取失败：返回通用预览失败信息，服务端日志保留具体原因，响应不泄露
  文件系统内部路径。

## 7. NAS、性能与资源生命周期

- 选项接口只读取元数据，不读取完整信号块。
- 一次预览请求只读取一次事件时间窗并生成两张图，避免两次 NAS I/O。
- Distance 范围只减少通道数，不扩大固定事件时间窗。
- 同一页面同时只允许一个预览请求；新事件选择通过 AbortController 取消旧请求。
- 后端不建立跨进程内存缓存，避免多 worker 一致性和无界内存问题。
- Base64 解码后的 Blob URL 在重置、事件切换、响应替换和组件卸载时全部释放。

## 8. 测试与验收

后端测试：

- 四类主检测器从事件原配置快照解析正确频段；
- 配置更新后，历史事件仍使用原处理运行配置；
- 自动和完整 Distance 范围来自真实通道距离；
- 人工范围按闭区间映射通道并排除坏通道；
- 一次读取生成两张有效 PNG，滤波 PNG 标题所需上下文正确；
- 非数字、逆序、越界、空通道、404、源文件缺失和指纹变化返回正确错误；
- 请求不创建或更新数据库记录，不在 ArtifactStore 产生文件；
- 新处理事件的永久滤波 PNG 标题包含主检测器和频段。

前端测试：

- 显示可用/自动范围、滤波频段和主检测器；
- 合法提交一次请求并同时替换两张瀑布图；
- 波形、PSD、STFT 不变；
- 非法输入阻止提交并显示错误；
- 重置恢复永久图件并释放临时 URL；
- 事件切换取消旧请求、忽略迟到结果并释放资源；
- 请求失败保留当前图件；
- 全屏和下载使用当前永久或临时图件。

端到端验收使用当前 JJK 事件：

- 页面显示事件原运行的主检测器和滤波频段；
- 选择一个小于自动范围的合法 Distance 区间；
- 两张瀑布图的 Distance 轴都变为人工区间；
- 滤波 PNG 标题显示正确频段；
- 波形、PSD、STFT 保持不变；
- 全屏图完整且关闭按钮不遮挡；
- 恢复自动范围后显示原始审计图件；
- 数据库记录数和 ArtifactStore 文件集合在预览前后完全一致。

## 9. 非目标与取舍

本次不支持在 PNG 上拖拽框选，不增加站点级处理距离范围，不保存派生预览，
不允许修改事件时间窗，不重新计算波形/PSD/STFT，不改变检测、融合、分类、特征或
时区语义。

前端裁剪 PNG 虽然实现简单，但不能可靠映射物理 Distance、重新计算颜色范围或
保持科学可复现性，因此不采用。预先生成全距离高分辨率数据会增加 NAS 存储和处理
负担，也不采用。
