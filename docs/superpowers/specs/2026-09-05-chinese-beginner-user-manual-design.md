# DAS Sentinel 中文零基础操作手册设计

## 目标

为不具备编程和 DAS 数据处理经验的日常使用者制作一份中文版 Word 操作手册。读者应能依照图文步骤打开系统、理解主要页面、使用 Z 盘 JJK 数据发起分析、查看图件、生成指定距离范围的临时瀑布图并完成人工复核。手册同时解释事件页面显示的全部 28 个事件特征，但不把任何单个参数描述为事件类别的确定结论。

## 交付物

- 一份可编辑、可打印的中文 Word 文档。
- 文档标题为“DAS Sentinel 中文零基础操作手册”。
- 文档使用这台电脑当前实际访问地址 `http://127.0.0.1:18000`。
- 文档包含当前软件界面截图，但不展示管理员密码、会话信息或其他密钥。
- Word 文档经过逐页渲染检查，确保文字、截图和表格没有遮挡、截断或乱码。

## 读者和权限边界

主要读者是只会进行常规 Windows 操作的日常使用者。普通用户步骤使用醒目的“照着做”提示；需要命令行、密钥、首次部署或系统配置的内容单独标为“仅管理员操作”。手册不记录管理员明文密码，也不要求普通用户查看或修改 `.env`、SQLite 数据库、Python 环境或服务进程。

Z 盘 JJK 原始数据始终按只读数据处理。手册明确禁止移动、重命名、覆盖或删除原始 HDF5 文件，并说明软件的数据库、模型和图件产物与原始数据分开保存。

## 文档结构

1. 软件用途：解释 DAS Sentinel、事件检测、机器标签和人工复核。
2. 开机后使用：检查软件是否已运行、打开浏览器地址、识别正常页面和健康状态。
3. 十分钟快速上手：登录、检查站点、确认 JJK 数据目录、扫描、查看任务、打开事件、查看图件和保存人工复核。
4. 页面详解：运行总览、站点、任务、事件复核和模型页面。
5. 图件详解：波形、原始瀑布图、滤波瀑布图、PSD 和 STFT。
6. 距离预览：解释自动范围、可用范围、滤波频段，以及人工输入起始和结束距离的方法。
7. 事件特征参数词典：解释全部 28 个参数。
8. 常见问题：登录失败、页面打不开、Z 盘不可用、扫描不到文件、任务失败、预览失败和图片显示异常。
9. 安全注意事项：原始数据保护、密码保护、人工复核和模型判断边界。
10. 管理员附录：说明当前本机运行方式与 Docker/NAS 部署边界。

## 快速上手流程

快速上手章节只保留完成首次分析所需的最短路径。每一步包含“看到什么”“点击哪里”“正常结果是什么”和“没有出现正常结果怎么办”。流程为：

1. 访问 `http://127.0.0.1:18000`。
2. 使用管理员提供的密码登录。
3. 在站点页面确认站点已启用、时区为 Asia/Shanghai、光缆类型正确、数据路径指向 Z 盘 JJK 数据目录。
4. 发起扫描或分析任务，不修改原始文件。
5. 在任务页面等待任务进入成功状态；失败时记录错误信息。
6. 在事件复核页面选择事件并查看机器标签、检测证据、事件特征和图件。
7. 需要指定距离时，在可用范围内输入起始距离和结束距离，生成临时预览。
8. 综合图件、证据和参数选择人工标签，填写必要备注并保存。

## 事件特征参数词典

参数按六组排列：

- 时间特征：`duration_s`、`rise_time_s`、`pulse_count`、`pulse_interval_s`、`repetition_rate_hz`、`time_of_day_hours`。
- 频谱特征：`dominant_frequency_hz`、`bandwidth_hz`、`spectral_centroid_hz`、`spectral_entropy`、`band_energy_ratio_low_mid`、`band_energy_ratio_mid_high`。
- 空间特征：`distance_extent_m`、`energy_centroid_m`、`shallow_deep_energy_ratio`、`continuity`。
- 传播特征：`best_slowness_s_per_m`、`apparent_velocity_mps`、`direction`、`coherence`、`zero_slowness_flag`、`cross_channel_correlation`。
- 振幅统计：`rms`、`kurtosis`、`peak_median_ratio`。
- 环境信息：`site_id`、`cable_type`、`device_config`。

每一项均提供英文名称、中文名称、单位或取值范围、通俗含义、数值高低的通常解释、可能关联的事件类型和误判注意事项。规则阈值只引用当前源码中实际使用的条件，并明确标注为“软件当前规则，不是所有 DAS 站点的通用物理标准”。

当前规则说明包括：车辆视速度需位于站点配置范围，默认 2 至 60 米每秒；空间连续性不低于 0.5 和相干性不低于 0.5 会增加车辆证据；持续时间不超过 5 秒和峰值平均幅度比不低于 5 会增加爆破证据；持续时间不低于 15 秒，以及相干性不低于 0.6 且不是零慢度，会增加地震证据；零慢度标志会形成噪声证据。手册同时说明最终标签还可能结合相似事件和监督模型，不能按上述规则手工相加替代软件判断。

## 故障处理设计

每个问题使用同一模板：用户看到的现象、常见原因、按顺序执行的操作、停止操作并联系管理员的条件。普通用户不执行删除数据库、结束未知进程、修改密钥、强制重建容器或改写 Z 盘数据等高风险动作。

当前本机 18000 端口由本地 Python 服务提供，项目目录尚无可直接使用的 Docker `.env`。因此手册不会声称“只启动 Docker Desktop 就能恢复当前服务”。普通用户在页面打不开时先检查地址、网络盘和 Docker Desktop 状态；如果服务仍不可用，则记录画面和时间并联系管理员。Docker Compose 首次配置、密钥、CPU 或 GPU 模式以及 NAS 只读挂载放入管理员附录，并与日常操作明显分隔。

## 版式和验收

文档使用 A4 纵向页面、清晰的标题层级、可自动换页的表格和适合打印的中文字体。快速步骤使用短句和编号，事件特征使用重复表格结构，截图保持可读比例。最终验收包括：逐页检查全部渲染图、检查目录和标题顺序、核对 28 个参数无遗漏、核对实际页面名称和访问地址、确认无明文密码和密钥、确认没有指导普通用户修改 Z 盘原始文件。
