# 站点统一波形样本层

用户已确认先建立统一样本，再以相同数据划分比较随机森林和预训练模型。此次交付为可直接运行的离线数据集工具和数值加载接口；生产训练仍使用现有特征，后续模型适配必须显式接入新样本，不能宣称已经切换。

## 数据契约

- 每个样本是 float32 数值矩阵 `[distance, time]`，同时保存真实距离坐标、相对秒坐标、UTC 零点、单位和来源。禁止用瀑布图图片训练、拉伸距离或补造通道。
- 常规视图：60 秒、100 Hz；低频视图：600 秒、5 Hz。窗口围绕目标事件中心，起点向下对齐对应 UTC 采样网格。两视图均从全通道数据读取，站点扫描排除范围不限制样本保存。
- 常规保存抗混叠重采样后的数值，不做逐通道归一化或空间共模扣除，保留未来模型所需预处理自由。低频视图另带 0.01–0.4 Hz 滤波数组，使用前后各 300 秒真实上下文和额外 10 秒抗混叠上下文；原始重采样数组同样保留。
- 每套数据集以指定参考源文件固定真实通道网格与单位；不匹配的样本明确失败。非有限原始值、缺失时间上下文均拒绝导出，不能把缺失补成有效噪声。有限平直通道保留原数值但有效掩码为假。
- 站点区段用参数保存，JJK 本次取悬空 `[0,299)`、地表 `[299,499)`、井下 `[499,end]`；分别保存区域编号和建议识别掩码，悬空通道不参与默认识别。掩码不能解释为人工类别标签。
- 人工标签只属于目标的时间/通道范围，附同窗其他已复核目标；窗口其余部分未标注，不能自动当成噪声，也不能把整窗强制设为目标类别。长于视图窗口的目标拒绝导出该视图。

## 来源、分组和交付边界

- 从 SQLite 只读一致性快照读取最新人工标签，保存 review ID、时间、事件 ID、源文件标识和旧特征快照；不使用机器标签、目录到时或未复核候选作为真值。
- 清单先覆盖站点全部已复核常规事件，再按事件 ID 或 limit 导出，不能在截取后重新划分组。按站点 UTC 日分组，并合并两视图全部读取上下文发生重叠的日期组，避免重叠数据跨组；训练程序应按 group 分割，不能随机逐样本拆分。该规则不等同于已核实的地震目录关联。
- 同一目标两种视图共享 group 和标签来源。低频扫描独立标签尚不冒充常规数据库标签；提供无标签窗口导出用于真实低频验证，清楚标记不能直接监督训练。
- 输出新目录中的 manifest.json、report.json、样本 NPZ 和 JSON。NPZ 不含 pickle 对象。报告区分成功、失败，记录失败原因；不覆盖已有成果、不修改原始 HDF5、数据库、服务或 Git 历史。
- 提供 `python -m das_sentinel.waveform_dataset ...` 离线命令：准备清单、构建指定视图、导出显式 UTC 无标签窗口。只扫描显式提供的源目录（非递归），连续读取按元数据验证，跨日需要提供相邻目录。
- 本轮不安装深度学习框架、不自动发布模型；文档说明后续 DASNet 等候选需验证权重、输入预处理与本站域差异，再在同组划分上离线比较。

## 验收

测试固定形状/坐标、100 Hz 抗混叠与原 5 Hz 行为兼容、跨文件连续性、低频真实上下文、标签范围、只读最新复核快照、分组不泄漏、失败不伪造有效样本及无 pickle 加载。用 JJK 人工复核事件及 6 月 16 日真实低频段构建小批样本，报告实际形状、掩码、来源和耗时，保存全部既有未提交改动。
