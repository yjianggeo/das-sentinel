# 全通道时间窗事件与多标签训练设计草稿

状态：用户于 2026-09-15 确认本方案，进入实施。沿用 fix/jjk-scan-progress 工作树及已有未提交修改。实施与上线证据另记于同名计划和进度记录。

## 目标与首版选择

复核对象、机器分类对象和训练样本统一为站点级全通道时间窗。局部通道触发成为窗内证据，不再分别生成大量事件与训练标签。此次先处理非低频。

推荐使用 UTC 整分钟对齐、60 秒不重叠的主窗。读取和滤波可使用窗外上下文，算法内部可重叠，但输出始终归属唯一主窗。时间统一到 100 Hz，保留 0.5–40 Hz 常规频段；不声称覆盖原始 50 Hz 以上或 0.01 Hz 面波。

另一个可行方案是自适应事件起止、再抽取固定模型窗。它更贴近持续过程的边界，但还需要起止识别、长事件切分和对应标签规则。首版选择固定主窗，便于唯一身份、缓存和人工整窗复核；以后依据真实验证再调整窗长，而非每个局部触发生成自己的重叠窗口。

固定主窗不代表独立物理地震。一场地震可能跨多个主窗，目录事件 ID、连续来源和重叠上下文在数据划分时合组，不能把这些窗口分散到训练和测试集。目录 P/S 窗只提供关联线索，不定义训练真值，也不限制实际读取时长。

## 已核验现状

- pipeline.py 对局部时空候选融合后逐事件分类和出图；screening.py 要求空间交集，因此同时发生在不相交通道段的触发保留为多个事件。
- 生产训练仍以局部 ROI 的 25 个数值特征训练随机森林。离线已经保存 60 秒全通道数组，但 DASNet 和自监督适配器仍围绕人工 ROI 聚合特征；现有分类头不是整窗多标签模型。
- 旧 60 秒数组围绕各 ROI 中点取窗，并未按 UTC 整分钟对齐；不能直接改时间戳后充作新主窗。只有实际起止、来源和处理契约均吻合时才可复用，否则重新读取。
- Event 绑定单次单文件 ProcessingRun，唯一约束只在 run 内；Review 和 Classification 都保存单标签。仅扩展 channel_start/channel_stop 或数组形状不能完成本次转换。
- 2026-09-15 只读统计：2,112 个旧 ROI 按起始时间归入 420 个一分钟区间；2023-09-27 的 239 个 ROI 位于 6 个源文件、6 个一分钟区间，数量为 12/67/73/6/18/63。这只是起始时间分箱，不能替代完整一分钟波形覆盖核验。
- 当前 1,025 个有最新人工标签的 ROI 仅覆盖 308 个主窗，其中 33 个主窗含多种旧 ROI 标签。旧局部噪声标签尤其不能代表整个窗口都无信号。

## 事件身份、读取和数据完整性

1. 建立站点级窗口身份：site_id、start_utc、duration_s；start 必须 UTC 整分钟、end=start+60s。同站点同主窗只产生一个复核对象，不依赖检测通道、触发器、目录相位、源文件名或重试任务 ID。
2. 分析版本与窗口身份分离。来源指纹、实际读取区间、时间轴、网格、处理配置、模型版本和结果哈希保留在分析记录；重新分析不能复制事件或覆盖旧人工审查记录。
3. 按真实时间拼接覆盖窗口的源文件，跨分钟/跨日均以元数据为准。缺失、冲突覆盖、非有限波形或窗口内网格变化必须报告失败/待补数据；不能补成正常噪声窗口。
4. 原始数值样本保存全部源通道及真实距离坐标、有效性掩码。JJK 0–299 m 悬空、299–499 m 地表、之后井下的区段含义保留。识别采用站点保存的扫描范围和坏道掩码；被排除通道仍在原始数组和全距离预览中，但不参与目标分类统计。整窗复核需清楚显示有效识别范围。
5. 保留文件原生通道数与坐标，不把 832、834、1663 等通道文件强裁成同样道号网格。同一站点统一时间/单位/处理协议，模型以全卷积和按真实距离分区汇总得到固定长度输出；必要的批次 padding 必须携带掩码。可变形状不代表跨网格等价，训练和验证按网格分层报告，未验证的网格不能直接上线自动分类。

## 检测与整窗特征

局部 STA/LTA、分频带能量、相干性和传播轨迹继续提供位置/到时证据。通过已有质量筛选的信号按主窗汇总，主窗只创建一次事件；可疑局部信号不要求在全光缆同时增强才能入选。局部证据强度仍在时空相容的证据组内判断，不能因不同位置、不同时间各有一次弱触发就互相增强为强证据。

每个完整扫描的主窗保存轻量分析记录。默认推荐复核只收录通过候选筛选或有关联目录线索的主窗；完整但无触发的窗口保留为背景抽样来源，不全部进入推荐队列，也不自动标成噪声。训练中的背景负例仍须经过人工整窗确认。

整窗特征直接从整窗有效二维波形计算，不能平均或拼接旧 ROI 特征冒充。至少保留：各频带能量的通道分布与时间变化、有效/活跃通道比例、连续空间覆盖、相干性及时移相关、传播轨迹、地表/井下分区统计、峰值及分位数、质量与背景指标。不能先把所有通道平均为一条波形再分类。

特征输出使用新版本 schema，与旧 25 特征向量隔离。缺失测量仍可辨识为不可用，不能把不可计算的相关性填作有效零值。机器预测来自整窗模型，旧 ROI 的机器类别只在历史证据中展示。

整窗显示一套全距离图件，局部证据可叠加和展开。默认主图和整窗特征覆盖同一主窗；前后背景/滤波保护区明确区分。顶部本地绝对参考时间、坐标轴相对秒数沿用现行形式。

## 多标签与复核

地震、爆破、车辆分别保存“存在／不存在／未确定”，互相独立；例如地震和车辆都可为存在。每类的判定作用于主窗内有效识别范围，未选择的类别不能自动作为训练负标签。

把原“噪声”解释为“仅背景”：只有三种目标类别都经整窗检查确认为不存在时才成立。噪声强度、风噪等背景可以另作质量说明；有地震并伴有背景噪声不应因此改成仅背景。未知/未确定不作为不存在。

旧 ROI 与窗口建立可追溯链接，人工类别显示为局部线索；不自动把局部标签覆盖到整窗。整窗标签保存自己的审核历史和数据/范围版本。来源或识别范围实质变化时，旧整窗审核需提示不再匹配当前输入。优先复核已关联目录且尚无整窗审核的主窗，保留此前 2023/2024 批次优先级。

## 模型与训练

统一契约为全通道二维数值波形、真实坐标、有效及识别掩码、60 秒相对时间轴。网络的输入平面和 DAS 道数分别表示；道数作为二维空间轴。计算可以在内部切块，但必须覆盖全部有效识别区，并先汇总到整窗再计算分类损失，不能把各块当作独立已标事件。

第一版用 PyTorch 的轻量二维卷积编码器，保留分区均值/峰值等汇总，接三个独立的多标签输出。另在同一批整窗标签与划分上比较整窗统计特征的传统模型基线。DASNet/现自监督编码器可作为离线初始化对照，但必须移除 ROI 聚合依赖、重新拟合整窗头并独立验证，不能宣称旧 ROI 头直接适用或预训练必然改善精度。

首轮训练从一个已经核实物理坐标与单位的同网格队列开始。不同年份的窗口仍可读取和复核，但未验证网格的自动分类保持待定；通道数相同也不代表网格相同，现有快照中两个 832 道网格分别覆盖 3,324 m 与 6,648 m。旧编码器若改用整窗前向，其归一化统计也会变化，必须重算特征。新整窗模型尚未训练或未通过验证时，界面展示检测证据和待定状态，不用旧 ROI 分类头填充整窗机器标签。

使用逐类二元损失并忽略未确定标签；类别权重、标准化和阈值只从训练/开发集确定。推理与训练共享相同预处理与掩码。测试集以独立日期、目录地震和源上下文联合隔离，同一主窗及其增强版本只出现于一个划分。统计每类确认的正例/负例和独立来源数量，不能拿旧 ROI 数量充作整窗训练样本数。

使用旧自监督权重时，额外核对其预训练波形清单：新测试窗口及读取上下文若已被预训练使用，必须调整留出或重新预训练，不能声称是未见波形的独立测试。没有明确震源关联的样本只能报告日期隔离，不能声称已证明震源独立。

报告每类召回率、精确率、PR 指标、多标签宏/微 F1、每小时误报窗口、漏掉的目录关联人工确认信号、每获得一个有效标签需要复核的窗口数及推理耗时。不套用旧单标签四分类指标来声称通过发布门槛；类别或独立数据不足时只保存离线候选。

## 扫描任务及兼容边界

保留旧数据库事件、标签、旧任务快照和已训练模型，不把它们原地改为新的语义。新队列和整窗训练默认使用窗口对象；旧 ROI 只作为历史/局部证据可追溯。

现有 1,151 个排队任务是旧单文件扫描快照，不能默认为已转成新窗口扫描。实施时先备份并生成源文件到主窗的映射报告，校验完整覆盖与唯一窗口后，再让新扫描任务使用新协议。取消任务不恢复；不同时运行新旧扫描去重复读取同一批数据。具体队列替换动作必须在可审查映射和回退记录齐备后执行。

当前 worker 因单文件 208 个事件提交 1,248 项图件、超过 600 项上限而退出。新协议还要处理单事件 64 条 evidence 上限：完整局部证据须独立保存或分批提交，主响应可给摘要；禁止静默截断，也不取消所有大小限制。能够归属到单项任务的结果格式/大小错误应记录为任务失败并允许 worker 继续可运行任务；身份或授权一致性错误仍须停止并报告，不能笼统吞掉所有协议异常。

## 验收与实施顺序

先完成窗口身份/跨文件读取及整窗多标签数据契约；再接检测证据聚合、整窗测量/图件和复核界面；最后导出整窗审核样本，训练并比较新模型。模型达不到要求时，明确保持待定/候选状态。

- 同一分钟内多道同时触发、相差一秒、重复任务和重叠计算块均只生成一个窗口对象；完整证据可追溯。
- 跨分钟边界不遗漏信号；相邻主窗不重复采样归属，但同一持续地震的主窗不得跨训练/测试。
- 全通道样本保留扫描排除区，分类实际掩码与站点范围一致；非法缺口和坐标错配不得变成有效噪声。
- 整窗地震+车辆标签保存、重载、训练及推理一致；未确定项不进入负例损失；旧标签逐行保留。
- 2023-09-27 真实数据须重新核验完整窗口覆盖，用全距离整窗图件复核，与 239 个 ROI 的来源映射对应；本轮计数不预先保证6个完整窗口均可用。
- 新前后端/API、模型加载、任务失败隔离和固定划分回归通过后再上线；不推送或合并 GitHub。
