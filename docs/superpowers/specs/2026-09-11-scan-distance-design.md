# 站点扫描距离范围

用户需求：站点可设置实际参与扫描的光缆距离，例如 JJK 排除前约 300 m 悬空光缆，减少风噪候选。

采用站点处理配置保存 `scan_distance_start_m`、`scan_distance_stop_m`。两字段默认 null（该端不限）；数值须有限且非负，同时设置时终点大于起点。按原文件光缆距离坐标选择，边界包含，不把距离自动解释为井深。不修改原文件。

站点页提供“扫描距离”编辑表单和当前范围，任务页在站点扫描入口显示当前范围及设置入口。保存创建新的处理配置版本；任务沿用创建时的配置 ID，已排队、已完成任务和历史标签不改变。旧配置缺字段等价于不限。PATCH 明确 null 可清除对应边界，省略保持原值。

检测前屏蔽范围外数据，并在幅值归一化、坏道统计、共模估计及空间窗口划分之前应用；保留原始数据列数和通道索引。v2 的无效通道掩码重新计算不能重新纳入屏蔽通道。事件分类所用预处理和测量采用同一范围。原始数据及人工临时预览仍可查看全距离。

指定范围与文件距离无交集时任务明确报错，不能静默改为全通道。范围不同导致新 profile，沿用现有 source/profile/pipeline 去重规则。此次只提供设置功能和部署验证，不自动创建扫描任务。

验证：配置和 PATCH 边界/清除/版本；合成范围外强脉冲被排除而范围内事件保留；改变范围外幅值不影响范围内结果；原始通道索引；无交集提示；前端保存/恢复不限/当前范围；全量检查与本地部署。
