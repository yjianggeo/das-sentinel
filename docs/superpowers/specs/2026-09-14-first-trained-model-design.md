# JJK 第一版训练模型

用户已授权持续优化、训练，直至得到第一版训练模型。本次沿用 fix/jjk-scan-progress 工作目录，保留全部先前改动；不推送、不发布模型、不改人工标签。

## 数据与评价

最新人工标签 739 条：地震 40、爆破 35、交通 30、噪声 634。当前 832 通道、0–3324 m、1000 Hz 原始网格有 687 条，作为特征和波形公平比较的共同总体。统一波形为全通道 60 秒、100 Hz；人工标签只监督各自 ROI，悬空段不参与分类。低频 5 Hz 视图不输入要求 2–10 Hz 与 >10 Hz 频带的 DASNet。

沿用完整清单预先确定的日期及重叠上下文分组。固定测试集在拟合前保存于 manual-work/first-model-20260914/split-common.json：77 条，地震 5、爆破 5、交通 3、噪声 64。开发集 610 条，四个内部日期折。波形缺失、无效 ROI 等可用性排除必须在模型拟合前记录；公平比较只能使用共同可用样本，绝不根据预测结果修改测试集。

预先比较：现有 25 特征平衡随机森林；去掉 time_of_day_hours 的 24 特征平衡随机森林及 ExtraTrees（叶节点 1、3）；DASNet 冻结编码器的 ROI 特征加标准化、平衡 LogisticRegression（C=0.01、0.1、1）。模型选择只依据内部组间验证 macro-F1，分数相差不超过 0.01 时优先不依赖时刻且更简单的方案。选定方案后测试集只评估一次；最后可用全体可用人工标签重训交付候选，但区分测试时模型与最终重训模型。

## 训练入口修复

原固定 StratifiedGroupKFold 可能遗漏某一折的爆破。共享分组函数先保留已有效的旧分组，否则用确定性、有类别覆盖约束的组分配。每折训练和验证均有全部类别、组互斥、不拆日期；不可行时明确失败。样本数量、五折和发布阈值不降低。训练就绪检查与训练器使用同一函数。

## DASNet 迁移

使用 AI4EPS DASNet-v1 官方 checkpoint，核对发布 SHA256 f1b0e1ee00a5a4a818b4bcfb70205bcbafd0db38acfa6d04537456576ae9c590，保留 MIT 许可。仅隔离环境安装 CPU PyTorch，不改变线上依赖。采用安全 weights_only 加载，严格匹配修改过 layer1 步长的 ResNet50 主干；原海洋类别头不映射到本站点四类。

预处理复现发布代码的应变率原始、2–10 Hz、>10 Hz 三视图及逐通道标准化。采用明确记录的 CPU 尺寸适配，再按人工 ROI 从特征图聚合。最终输入固定为 6000 时间点 × 256 距离像素，保留全部 100 Hz 时间采样，仅压缩空间轴。最初 1024 时间像素方案在训练前被物理频带检查淘汰：17.1 像素/秒会压掉高频细节；完整时间实测约 1.15 秒/条、峰值 1.94 GiB，符合机器条件。记录尺寸变化使结果不能被称为原版 DASNet 原生精度。不进行全模型微调。

重叠波形读取可合并后精确切回原时间网格；滤波算法、实际数据覆盖、人工 ROI 与掩码规则保持一致。在模型拟合前使用三条不同窗口检验批读与原逐条读取的误差，要求相对 RMS 误差 ≤ 1e-7，最大绝对误差 ≤ max(1e-8, 1e-6 × 原波形 RMS)。结果称数值容差一致，不称逐位相同。失败时回退原逐条读取。

## 交付与限制

必须得到实际拟合、保存并重新加载预测通过的首版模型。已有安全 bundle 格式的随机森林候选可登记到本地模型页；实验性波形分类头独立保存、提供可复现推理脚本与元数据，不伪装成线上支持的 RF bundle。未通过原发布门槛的候选不得激活。交付数据划分、参数、来源哈希、混淆矩阵、每类召回率和限制。样本极度不平衡，测试交通仅 3 条，不作已具备生产精度的结论。

## 2026-09-14 可读性检查后的比较设计修订

原划分仅检查了标签源文件，未证明完整 60 秒及前后滤波上下文可读。全部源文件索引和真实导出检查揭示，原测试集可读地震为 0、开发交通为 19；原方案无法支持四类比较，保留原文件及校验值，不据此生成失真的四类测试分数。

独立正式 API 的 739 条特征基线先训练并保存为 v1 candidate；它不依赖连续波形导出，分数不用于本实验选型。在任何比较实验拟合前，依据可读性、类别数量、完整清单日期组重新制定一次划分。预检 586 条可用、28 组：测试 95（地震 4、爆破 2、交通 2、噪声 87），开发 491（21、30、20、420）；保留四个完整内部验证折。方案与原因另存 split-available-provisional.json 及 reason.json；待实际导出完整符合后才冻结为 split-available.json。原组 ID、七个模型配方、选型规则、原始标签、源数据连续性门限均保持不变。任何额外真实读取失败均要先核验结构，不能按模型预测排除事件。

批读数值验证中历史 2024-06-09 的窗口未通过原绝对界限，因此使用原逐条读取。仅对通过对照的 2026-05-04 与 2026-07-28 两组启用批读；额外偏移对照及 float32 表示尺度诊断完整保留，不宣称所有日期逐位相等。
