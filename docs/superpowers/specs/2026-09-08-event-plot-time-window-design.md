# DAS Sentinel 事件图表最小时间窗与精确时间轴设计

日期：2026-09-08

状态：用户已确认方案；本书面规格待复核，尚未实施。

## 1. 目标与范围

本次只优化事件图表显示：

1. 原始瀑布图、滤波瀑布图和波形使用相同的显示时间窗，真实数据允许时至少为 3 秒。
2. 顶部显示精确到整秒的本地参考日期时间及站点时区；底部显示相对该参考的精确秒数，移除 UTC 时间刻度轴。
3. 新生成的正式图采用新规则；已有事件通过临时重绘查看新版三张图，保留旧证据图。
4. 不改变事件检测、融合、分类、特征提取、PSD、STFT 的分析范围与计算输入。

前置的任务取消操作已完成：本次取消 1 个运行中任务和 1,315 个排队任务；取消后的运行中和排队任务均为 0，保留 17 个已完成任务。本次图表优化不重新排队这些任务。

不涉及修改 NAS 原始数据、覆盖历史 PNG、修改其校验和、数据库迁移、跨文件拼接或重新检测。

## 2. 已核对的根因

`pipeline.py` 的 `_event_window` 已按处理配置读取事件前后上下文，但 `artifacts.py` 的 `_event_selection` 在绘图时再次裁回事件自身的样本区间。事件本身较短时，正式瀑布图和波形也会很短。

`artifacts.py` 的 `_time_axes` 将两套时间轴都格式化为 `%H:%M:%S`，而自动刻度可能落在同一秒内，因而出现多个相同标签。

临时瀑布预览已经使用带上下文的数据块，但没有保证最小 3 秒，也未提供临时波形。历史图是经过 SHA256 校验的静态证据，单纯重启或刷新页面不会更新旧图，直接覆盖会破坏完整性校验。

## 3. 获批方案与取舍

采用“显示窗口独立于分析窗口，历史事件按需临时重绘”的方案。保留现有预览入口，只补充同窗波形和必要的时间窗说明，不引入后台重绘任务。

不采用扩大所有分析窗口的方案：去趋势、滤波、坏道识别和归一化依赖整块输入，扩大分析数据会间接改变特征及分类。也不采用覆盖历史证据图或重跑检测的方案：这些操作改变历史结果或任务状态，不属于本次显示优化。

## 4. 统一显示窗口

### 4.1 计算规则

以源文件的全局样本半开区间 `[start, stop)` 计算窗口；采样率记为 `fs`，最小目标样本数为 `ceil(3 * fs)`。时长定义为 `(stop - start) / fs`，不是最后一个采样点时间减去第一个采样点时间。

先保留完整事件及现有配置的前后上下文，已有超过 3 秒的窗口不缩短。如果有效窗口不足最小样本数，围绕事件向两侧尽量均匀扩展；奇数个额外样本优先分配给结束侧。一侧碰到文件边界时，将剩余扩展量补到另一侧。

窗口始终限制在单个源文件内。长事件不截断。若整份源文件不足 3 秒，展示全部真实样本，在三张图中注明“源文件不足 3 秒，显示实际长度”，并显示实际时长；不补零、不拉伸时间、不借用相邻文件，也不靠轴外空白伪造 3 秒长度。

原始瀑布图、滤波瀑布图、波形必须复用同一个窗口结果和时间参考。事件起止、峰值及已有候选标记的位置不因显示扩展而平移。

### 4.2 与分析数据隔离

保留现有分析数据块、事件分析切片及其滤波数据，用于特征、分类、PSD、STFT 和原证据范围记录。

默认上下文足够时，直接从已有数据块选择显示窗口，不额外读取 NAS。只有显示窗口超出已有分析数据块时，才额外读取、预处理显示专用数据；这些数组和坏道结果仅用于三张显示图，不回流到分析或分类。

显示图记录真实的显示样本范围、时长以及原有滤波频段。显示范围扩大不改变事件本身的起止时间、通道范围或原分析证据的语义。

## 5. 本地参考时间与相对秒数

顶部不再排列另一套时间刻度，而显示一个明确的参考，例如：

`本地参考时间：2026-09-08 15:28:03 (Asia/Shanghai)`

参考值由显示窗口首个样本时间转换到站点时区后向下截到整秒得到；日期必须保留。内部时间坐标仍使用绝对时间，以兼容现有事件边线和候选标记。

底部标注“相对上述参考时间 (s)”。标签按实际刻度间距选择足够的小数位，例如 `0.00、0.25、0.50`，避免重复标签、负零和过密重叠。较长窗口可使用整数或更疏的刻度，不固定为每 0.25 秒一个刻度。

如果首个样本在 `15:28:03.234`，顶部参考仍为 `15:28:03`，该样本对应 `0.234 s`，不能错误标成零。跨秒、跨分钟、跨午夜时相对秒数保持连续，顶部日期不丢失。

三张图采用相同刻度位置、参考和可视时间边界。保留事件结束的排他边界可见性；单采样图也按采样周期设置边界，不使用日期坐标默认的半天宽度。

## 6. 历史事件临时重绘

### 6.1 后端

沿用 `POST /api/v1/events/{event_id}/waterfall-preview`，在一次有界源读取及显示预处理后生成原始瀑布图、滤波瀑布图和代表波形，三张图共享窗口、筛选后的有效通道和滤波频段。

手动模式保留现有 `distance_start_m`、`distance_stop_m` 参数，两值必须同时提供、有限且严格递增。增加空对象 `{}` 请求表示按原事件的 `[channel_start, channel_stop)` 自动选道；不能简单把自动距离的最小值、最大值作为手动请求发送，因为单通道事件两值相等，非单调距离还可能选入原事件之外的通道。

沿用现有历史事件、源文件、处理配置、模型版本和候选证据的绑定校验。响应仅增加必填 `waveform_png_base64`，采用与另两张 PNG 一样的长度限制。现有两张瀑布图及距离、频段字段继续保留。时长和短源说明直接绘入三张图片，不另增时间元数据接口。

临时波形显示所选距离范围内有效通道的稳健代表信号，不把手动距离重选后的信号冒充原始分析输入；事件和候选时间标记仍使用原记录。全局样本偏移只换算一次，不能把块起点时间再重复累加偏移。

历史数据库事件没有独立的峰值样本字段；从已存候选按原融合规则恢复峰值标记，即最高分候选优先、同分取最早峰值。不重新运行融合或改变事件记录。通道选择使用读取块内的局部索引，保留源通道映射；不为复用绘图函数而改写历史事件的全局通道范围。

沿用认证、CSRF、源指纹复检及现有的 30,000 样本、256 通道读取上限；在读取大数组前完成范围检查。若最小窗口超过资源上限，返回明确的范围错误，不静默缩成不足 3 秒的图，也不放宽上限。

源文件缺失、改变或历史绑定不一致时沿用冲突错误，界面继续提供原始证据图。三张临时图片要么整体成功返回，要么整体失败；不混用不同请求的图片。

### 6.2 前端

沿用事件详情中的临时预览操作：用户可保持系统自动距离范围，或输入手动距离后点击“生成临时预览”。无需重新扫描或运行分析任务。

初始及重置后为自动模式，发送 `{}`；修改任一距离输入后为手动模式，发送两个距离值并按现有规则校验，空输入不视为零。图中区分自动事件范围与人工距离范围，单通道自动范围不被误判为非法手动区间。

预览成功后同时替换当前查看的两张瀑布图和波形，明确标注“临时预览，不修改原始证据”，并在图内显示实际窗口长度及不足 3 秒时的原因。已有滤波频段和距离信息保留。

沿用“重置临时预览”恢复原图及输入，三张图一起恢复；仅修改输入时不伪装当前已经生成的图。切换事件、卸载组件或被更新请求取代时丢弃过期响应，释放全部临时图片 URL。生成过程中沿用忙碌和禁用状态，避免重复提交，不新增后台渲染取消机制。第三张图片解码失败时，释放本次已创建的图片 URL，保留此前完整预览，避免半套更新。

当前图的下载链接继续下载当前显示内容，波形预览也采用临时图片链接；恢复原图后下载原始证据。PSD、STFT 和特征表不随临时预览替换。不会在打开事件时自动批量读取 NAS 或后台生成预览。

## 7. 验证与生效

实现时先补回归测试并观察失败，再进行最小修改：

- 窗口：中央短事件、文件首尾、长事件、源不足 3 秒、非整数采样率，以及已有长上下文不缩短。
- 时间轴：亚秒标签不重复；三图同参考；首样本非整秒；跨午夜；单采样；事件及候选排他结束边界不被遮挡。
- 隔离：扩展显示前后，特征和分类输入、PSD/STFT 数组及原分析证据范围保持不变。
- 预览：一次有界读取产生三图；手动距离和通道偏移正确；自动单通道及非单调距离选道正确；历史峰值标记正确；读取前拒绝超限；源指纹及数据库、历史图件不变；异常不返回半套图片。
- 前端：三图一起切换与恢复；不足 3 秒提示；忙碌状态；事件切换时旧响应失效；所有图片 URL 正确释放。
- 视觉：实际渲染短窗、跨日和不足 3 秒样例，检查刻度、标题、图例及图片高度，无重复标签或遮挡。

完成针对性测试、前后端回归和构建后，在保持任务取消状态的前提下部署。用一个已有事件生成临时预览验证新版三图，不重跑已取消任务、不批量重建历史证据。正式新图通过隔离测试数据验证；既有原图保持原样。
