# 窗口图片单击放大与疑似区域开关

用户要求取消全屏按钮，每张图片单击放大，并可开关瀑布图中的疑似区域。本轮按已授权界面行为直接实施；沿用既有工作树和未提交修改，不提交或推送。

设计：整窗原始/滤波图及局部图单击打开独立图片对话框，支持关闭、Esc、键盘焦点和下载。网页编号框点击仍选择局部区域，局部图片可再单击放大。区域开关默认开启，主界面和放大视图共享状态；关闭时同时移除图上编号/边框，区域列表保留。

原PNG已烧录区域框，所以新增受认证的 GET /event-windows/{id}/waterfall-preview?analysis_id=...&filtered=false，返回无框整窗PNG。现有region-preview新增show_regions=true，false返回相同裁切的无框图。两接口仅从经SHA验证的已保存100Hz数组绘图，不回读NAS、不改manifest/训练数值/标签/worker；旧接口默认兼容。开启时继续使用原登记PNG，关闭时请求无框图。
