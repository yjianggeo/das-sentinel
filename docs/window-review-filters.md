# 按人工复核类别浏览窗口

事件复核页面的“复核状态”新增：

- **已复核·地震类**：最新有效人工标签为地震类，包含爆破。
- **已复核·噪声类**：最新有效人工标签为噪声类，包含车辆。

保留“待复核”“已复核”和“全部状态”。类别筛选依据人工标签，与机器判断无关；待确定、输入已变更、配置已失效或继承依据失效的复核不计入两种已复核类别。

筛选继续与“窗口范围”（包括“只看收藏”）、站点和模型扫描批次组合，切换类别返回第一页。若要查看所有已复核地震或噪声窗口，将“窗口范围”设为“全部窗口”。进入“只看收藏”仍默认显示全部复核状态，再选择需要的类别即可。改判并保存后，沿用现有页面行为，点击“刷新窗口”重新应用当前筛选。

API：`GET /api/v1/event-windows?review_status=reviewed_earthquake` 或 `review_status=reviewed_noise`。类别条件在计算总数与分页前应用，并沿用当前分析、输入指纹及最新人工标签绑定。不修改标签、收藏、排序、模型或数据库结构。
