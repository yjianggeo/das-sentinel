# 训练准备度与推荐复核

事件复核页左上角可切换“全部事件”和“推荐复核”。默认打开全部事件；推荐模式按站点组织未复核候选，每批显示 20 组，可展开组内原事件，使用原来的图件和人工标签表单逐条复核。

## 怎样安排复核

- 先看“地震线索”：与同站点、同处理版本的人工地震参考比较信号特征，并结合已有目录到时窗口安排顺序。
- 2026-09-15 新增的 2023/2024 年目录关联任务中，与 P/S 到时窗相交的未复核事件优先于此前数据，推荐依据标记“本批目录优先”。后续扫描结果在“刷新推荐”时自动纳入；到时窗外的事件保持普通复核机会，已复核事件退出待复核池。
- 点击“推荐依据”展开信号相似性和目录关联说明；“目录来源”保留原目录链接，详细说明不挤占事件入口。
- 命中同一目录地震、同一 P/S 到时窗口的片段只占一个入口，跨源文件、不同通道和处理版本的片段可以在此一起浏览。先显示最多 3 个覆盖不同时间或通道的代表，其余在“查看组内片段”展开，每次增加 20 条；全部成员均可逐条选择，原事件和人工标签保留。
- 代表片段旁的“全距离预览”直接读取该源文件的完整距离范围，包含扫描排除的通道，仍按该次处理配置剔除坏道。时间范围是所选片段及原有绘图补边，至少 3 秒并受源文件边界限制；不会拼接整个跨文件目录到时窗。顶部绝对参考时间与坐标轴相对秒数沿用现有临时预览格式。
- 本批优先组排完后，继续查看“多样类型”和“抽查”。剩余队列通常按每 20 组中的 10 组地震线索、6 组多样类型、4 组固定随机抽查安排，某类不足时由剩余候选补齐。机器标签为噪声的事件仍有复核机会。
- 保存一条标签后，当前批次和详情保留，并显示“已复核”。点击“更新待复核批次”或“刷新推荐”会从剩余候选重新开始；未保存标签时，可以按“上一批／下一批”连续翻页。
- 推荐分仅表示查阅顺序，不是地震概率。原检测得分也不是分类置信度。此功能尚未经过新的人工复核评估，不能据此声称地震命中率已提高。

没有命中目录窗口的事件继续使用相似组：同站点、处理版本和源目录、共同空间交集、信号相近的片段，完整跨度不超过 120 秒，最多 20 条。超过 120 秒的单个片段独立保留。目录窗口入口和相似组都仅减少浏览重复，仍需逐条确认，不自动继承标签，也不把一个组当成一次独立地震。分组不删除或合并数据库事件。

信号比较只使用有限的时长、频谱、振幅和通道相关等测量，不将钟点、路径或机器标签当成地震证据。缺少兼容参考或有效特征时会说明原因，并保留候选。

## 如何补齐训练样本

模型页“训练准备度”按每个事件的最新人工标签，显示四类数量、UTC 日期覆盖和实际五个验证组中的类别数量。点击“刷新准备度”读取后续复核结果。

当前训练要求每类至少 20 条有效样本，特征结构一致，且五个验证组的训练集和测试集都覆盖四类。按生产训练使用的 UTC 日期和固定种子计算分组；每类达到 5 个日期是必要条件，仍可能存在缺类验证组。无法检查或未满足门槛时，训练按钮不可用。

2026-09-14 的只读基线中，已复核地震、爆破、交通各 30 条，噪声 594 条。主要缺口是爆破集中在 3 个 UTC 日期，使两个验证组没有爆破样本。应优先增加不同日期的真实爆破和地震等样本，避免继续重复标注相同背景噪声。不要为补足配额而强行标成某类；不确定的信号可保留待定。

日期不是独立物理事件，多个切片也不能代替更多独立地震。满足结构要求后仍要手动训练并验证模型质量；此功能不降低现有训练或发布门槛，不自动训练、发布模型。

低频连续扫描中的独立复核标签暂未进入原事件训练集。0.01–0.4 Hz 面波仍应使用低频页面及足够长的时间窗复核；不能因未命中 P/S 到时窗口或常规推荐得分偏低而判断为噪声。

## 目录与接口

本地可选文件 `app-data/review-catalog-windows.json` 使用 `schema_version: 1`，`windows` 中每条含 `site_id`、`catalog_id`、`phase`、`start_utc`、`end_utc`、`source_url`。时间必须包含时区，且开始早于结束。仅按同站点的 UTC 时间窗相交提供线索；文件缺失或损坏不阻断推荐。

窗口可选 `preferred_job_ids` 字符串数组，限定优先复核的任务。只有任务 ID 命中且时间窗相交的未复核事件获得额外推荐分；包含这类事件的目录窗口入口进入队首优先层，同窗口的旧任务可一起浏览，窗外片段不能借此进入。一个事件同时命中多个窗口时，优先归入自己任务被标记优先的窗口，再按实际时间重叠长度和稳定顺序选择唯一入口。不同 P/S 窗口分开，窗口 ID 不随成员增减改变。该标记只改变复核顺序，不改变机器分类、人工标签或模型输入；特征相似性仍只在兼容版本间计算。

2026-09-15 在原有 467 条 2023/2024 年窗口中绑定了此次 1,193 个已提交任务（1,289 条任务与窗口关联），导入时核对了数据库任务、站点、处理版本、源文件指纹及已验证窗口。总窗口数仍为 1,306；原窗口和来源均保留，不重复导入目录。队列每次请求动态读取事件，无需等整批扫描完成后再手动添加。

本次 JJK 使用此前已计算的 655 个目录事件、1,306 个 P/S 窗口，来自 2026-09-09 到时分析及 2026-04-21 至 2026-09-10 下载计划。后者目录截止时间为北京时间 2026-09-10 19:44:51。导入文件保存原来源文件路径和 SHA-256；每条窗口保留目录链接。这不是实时或完整地震目录，也未覆盖面波到时，目录关联不能直接用作人工标签。

- `GET /api/v1/sites/{site_id}/training-readiness`：训练结构、缺口、实际验证组和模型状态。
- `GET /api/v1/review-batches?site_id=…&offset=0&limit=20`：推荐组分页，`limit` 为 1–50，`offset` 从 0 开始。每个组的 `members` 包含全部未复核成员，`representatives` 包含 1–3 个代表，首位兼容原 `representative`。`catalog_window` 为目录 ID、相位、到时窗起止和来源链接，普通相似组为 `null`；顶层 `start_utc/end_utc` 仍表示实际成员覆盖范围。

两个接口均要求登录、只读，不拟合分类器、不读取原始 NAS 波形、不创建扫描或复核记录。固定数据输入下，推荐顺序稳定，每个未复核事件恰好出现在一个组中。标签发生变化后重算顺序；页面在本批保存后，点击“更新待复核批次”或“刷新推荐”时回到剩余池起点，避免继续沿用旧偏移跳过事件。
